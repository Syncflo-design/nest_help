Exporting Item Data

NestERP Help

What This Does

The Data Export tool lets you download your item catalogue as an Excel spreadsheet. Use it to audit your data — check for missing fields, missing images, incomplete pricing, or items that need updating.

Getting There

1 From the home screen, click Items (or navigate to the Item list)
2 Click the Export Data button in the top bar

Setting Up Your Export

3 DocType is pre-set to Item — leave this as is
4 File Type — select Excel
5 Select fields to export. Click on a field name to add it to your export. The fields you need depend on what you're auditing — see the tables below for each product category.
6 Add filters to narrow down which items are exported. For example:
  • Category = Home (for Home items only)
  • Category = Fashion (for Fashion items only)
  • Category = Ceramics (for Ceramics items only)
  • Item Group like Ardmore Home% (all Home sub-groups)
7 Click Export — the Excel file downloads to your computer

To quickly spot gaps, open the downloaded Excel, sort by the column you want to check (e.g. Image), and scroll to the blanks. Any row without an image URL needs a photo uploaded.
The export downloads what's currently in the system. It does not modify any data — it's safe to run as often as you like.
