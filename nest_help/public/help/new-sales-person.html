How to Create a New Sales Person

1 Go to /app/sales-person/new.
2 Enter the Sales Person Name (their full name as it should appear in reports).
3 Select the Parent Sales Person — this is usually Sales Team (the top-level group).
4 Click Save.

Add Them to a POS Store

After creating the Sales Person record, you need to add them to the relevant POS Profile so they can use the POS:

5 If the person does not already have a User account, create one first (see the Sales Persons help page for full instructions).
6 Open the relevant POS Profile at /app/pos-profile and add the user to the Applicable for Users table.
A Sales Person record tracks commissions and sales attribution. A User account is what lets them log in and appear in the POS dropdown. You typically need both.
