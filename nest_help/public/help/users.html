How to Manage User Accounts

1 Go to /app/user to see the full list of user accounts.
2 Click Add User to create a new account.
3 Fill in the required fields:
  • First Name and Last Name
  • Email — this becomes their login username
  • Set a password in the Set New Password field
4 Scroll down to the Roles section and assign the appropriate roles for the user (e.g. Sales Assistant, POS User A, System Manager).
5 Click Save.

Disabling a User

To disable a user account without deleting it, open their user record and uncheck the Enabled checkbox, then save. The user will no longer be able to log in but all their historical data is preserved.

You must be logged in as an Administrator or System Manager to create or modify user accounts.
