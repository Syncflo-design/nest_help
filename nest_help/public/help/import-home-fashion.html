Import Home/Fashion Items

NestERP Help

What This Does

This tool imports Home and Fashion product lines from an Excel spreadsheet into ERPNext. It creates the Item records with all category-specific fields (sub category, collection, design, colour, base cloth, size) and pricing. If quantities are included, stock is automatically received into your chosen warehouse.

New items are automatically synced to Sage after creation.

Steps

1 Click Import Home/Fashion from your home screen
2 Click Download Template (button at the top) to get the blank spreadsheet
3 Fill in the template with your items. Required columns: item_code and item_name. All other columns are optional but recommended.
4 Select the Company the items belong to
5 Select Category: Home or Fashion
6 Select the Target Warehouse where stock should be received (e.g. Main Distribution - ACT)
7 Upload your completed Excel file using the Upload Excel File field
8 Click Save — the import runs automatically
The import log shows which items were created, skipped (already exist), or had errors. If you included quantities in the qty column, a Stock Entry is created to receive the stock into the target warehouse.
