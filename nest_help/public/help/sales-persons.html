Adding Sales Staff to a POS Store

Ardmore — ERPNext Training Guide

Purpose

When a new sales person joins a store, two things need to happen in ERPNext:

  1. They need a User account (so they appear in the POS dropdown)
  2. They need to be added to the store's POS Profile (so the POS knows they work there)

Before You Start

  • You must be logged in as an Administrator or System Manager
  • Know the person's full name and an email address (this becomes their login ID — it doesn't need to be a real email for internal staff, e.g. happiness@ardmore.local)
  • Know which POS Profile (store) they belong to

Step 1: Create the User Account

1 Go to the URL bar and type: /app/user/new
2 Fill in:
  • First Name — the person's first name
  • Last Name — the person's last name
  • Email — their email address (this is also their username)
3 Scroll down to Roles and add these two roles:
  • POS User A
  • Sales Assistant
4 Uncheck Send Welcome Email (unless you want them to receive a login email)
5 Set a password in the Set New Password field
6 Click Save

Step 2: Add Them to the POS Profile

1 Go to the URL bar and type: /app/pos-profile
2 Open the POS Profile for the store (e.g. POS_Test2, Airport, Joburg)
3 Scroll down to Applicable for Users
4 Click Add Row
5 In the User field, search for and select the person you just created
6 Leave Default unchecked (unless this is the primary user for the store)
7 Click Save
The new person will immediately appear in the "Select POS User" dropdown when opening the POS. The store manager logs in with their account, then selects the sales person from the dropdown. Each sale is attributed to whoever is selected.

To Remove a Sales Person

  1. Open the POS Profile for the store
  2. In the Applicable for Users table, delete their row
  3. Click Save
  4. Optionally, disable their User account at /app/user/(their email) — uncheck Enabled
