Insights (Analytics)

NestERP Help

What This Does

Insights is a powerful reporting and analytics tool built into NestERP. It lets you build custom SQL queries, create visualisation charts, and assemble dashboards — all without writing code.

How to Use It

1 Click Insights from the Nest Home dashboard. It opens in a new browser tab.
2 To create a new query, click New Query. Select the data source tables and build your query using the visual builder or write raw SQL.
3 Run the query to see results in a table. Adjust filters, grouping, and sorting as needed.
4 To visualise the data, click Add Chart and select a chart type (bar, line, pie, etc.). Configure axes and labels.
5 Save your queries and charts, then add them to a Dashboard for an at-a-glance overview that you can share with your team.
Insights queries read directly from the database. Pre-built dashboards may already be available for your store — check the Dashboards section before building from scratch.
