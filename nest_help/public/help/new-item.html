How to Create a New Item

1 Click New Item from the Nest Home dashboard (or go to /app/item/new).
2 Enter an Item Code — this is the unique identifier for the product (e.g. SKU or internal code).
3 Enter the Item Name — the display name customers and staff will see.
4 Select an Item Group to categorise the product (e.g. Ceramics, Homeware, Art).
5 Set the Standard Selling Rate — the default selling price for this item.
6 Upload a product image by clicking the image placeholder at the top of the form.
7 Click Save to create the item.
The Item Code must be unique across the entire system. If you need to add stock for the new item, create a Stock Entry (Material Receipt) after saving.
